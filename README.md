# Hi, I'm Uniskela.

I build useful software for self-hosting, homelabs, and the spaces where systems have to work together.

Most of my projects begin with a real problem in my own infrastructure. I care about clear documentation, sensible defaults, guarded automation, and software that people can run for themselves.

## What I work with

TypeScript and Python for applications and tooling; Docker, OCI containers, and Linux for deployment; SQLite, REST, MCP, and GitHub Actions around the edges.

### [ADHD Progress Hub](https://github.com/uniskela/adhd-hub)

[![Latest release](https://img.shields.io/github/v/release/uniskela/adhd-hub?display_name=tag&sort=semver)](https://github.com/uniskela/adhd-hub/releases/latest)
[![Container images](https://github.com/uniskela/adhd-hub/actions/workflows/container.yml/badge.svg)](https://github.com/uniskela/adhd-hub/actions/workflows/container.yml)
[![License: MIT](https://img.shields.io/github/license/uniskela/adhd-hub)](https://github.com/uniskela/adhd-hub/blob/main/LICENSE)

A self-hosted source of truth for unfinished technical work. It helps coding agents spot overlapping tasks, preserve progress, and leave useful reminders so context survives between sessions.

`Python` · `MCP` · `REST` · `SQLite` · `Docker`

[Documentation](https://uniskela.github.io/adhd-hub/) · [Releases](https://github.com/uniskela/adhd-hub/releases) · [GHCR](https://github.com/users/uniskela/packages/container/package/adhd-hub)

Inspired by [shaheer-00/claude-adhd](https://github.com/shaheer-00/claude-adhd) and developed as a tool-agnostic MCP and REST hub.

### [TS6 Manager](https://github.com/uniskela/ts6-manager)
